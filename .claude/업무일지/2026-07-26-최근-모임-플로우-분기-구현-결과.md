## 구현 배경

랜딩 홈의 최근 모임 카드는 기존에 항상 `/meetings/{meetingId}/schedule`로 이동했다. 이 때문에 중간지점 찾기만 진행한 모임도 일정 조율 화면으로 열리는 문제가 있었다.

이번 구현에서는 백엔드가 내려주는 `availableFlows` 값을 기준으로 최근 모임 진입 경로를 분기했다.

## 캡처

두 플로우가 모두 가능한 최근 모임을 클릭하면 선택 UI를 표시한다.

![최근 모임 플로우 선택 UI](./images/2026-07-26-recent-meeting-flow-selector-mobile.png)

## 프론트 변경 사항

### 1. 최근 모임 응답 타입 확장

`MyMeetingResponse`에 `availableFlows?: MeetingFlow[]`를 추가했다.

```ts
export type MeetingFlow = "SCHEDULE" | "LOCATION";

export interface MyMeetingResponse {
  availableFlows?: MeetingFlow[];
  createdAt: string;
  hostName: string;
  isHost: boolean;
  meetingId: string;
  participantCount: number;
}
```

`availableFlows`는 백엔드 배포 전후 호환을 위해 optional로 뒀다.

### 2. 최근 모임 라우팅 유틸 추가

`getRecentMeetingNavigationTarget`을 추가해 분기 규칙을 컴포넌트 밖으로 분리했다.

| `availableFlows` | 동작 |
|---|---|
| `["SCHEDULE"]` | `/meetings/{meetingId}/schedule` |
| `["LOCATION"]` | `/meetings/{meetingId}/location/stations` |
| `["SCHEDULE", "LOCATION"]` | `null` 반환 후 선택 UI 표시 |
| 누락 또는 빈 배열 | 기존 동작 유지: 일정 화면 |

### 3. 선택 UI 추가

`RecentMeetingFlowDialog`를 추가했다. 기존 `Modal` 컴포넌트를 재사용해 다음 액션을 제공한다.

- `일정 조율 보기`
- `중간지점 보기`
- 바깥 영역 클릭 시 닫기

### 4. 모임 생성 flow 전송

백엔드가 최초 생성 플로우를 저장할 수 있도록 생성 요청에 `flow`를 포함했다.

```ts
flow: getCreateMeetingFlow(flow)
```

매핑 규칙:

| 라우트 파라미터 | 요청 flow |
|---|---|
| `location` | `LOCATION` |
| 그 외 | `SCHEDULE` |

## 남은 주의점

- 백엔드 배포 전에는 `availableFlows`가 없을 수 있으므로 일정 화면 fallback을 유지한다.
- `.worktrees/**` 내부 테스트가 별도 React 인스턴스 문제를 일으켜 프론트 전체 Vitest 실행 시 제외 옵션을 사용했다.
- 현재 작업트리에는 기존 위치 화면 관련 변경이 함께 남아 있으므로 커밋 시 파일 범위를 분리해야 한다.
